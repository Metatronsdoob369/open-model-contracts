# Notes Workspace

- `conversations/` — dated markdown logs of key threads (context, decisions, next steps).
- `ideas/` — short, actionable idea stubs (problem, hypothesis, next action).
- `research/pdf/` — source PDFs (e.g., arXiv papers, docs).
- `research/summaries/` — 1–2 page distilled summaries per PDF.
- `research/index.jsonl` — metadata rows with tags and optional embeddings for retrieval.

Conventions:
- Filenames: `YYYY-MM-DD-topic.md` for conversations; `topic.md` for ideas; `slug.pdf` for research.
- Each summary starts with Title, Source URL/DOI, Key Claims, Limitations, Relevance.
- When a contract/policy/workflow cites a paper, reference the summary filename and line.
