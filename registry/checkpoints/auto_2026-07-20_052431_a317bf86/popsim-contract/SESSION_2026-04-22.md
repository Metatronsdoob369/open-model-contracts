### 10. LuauShatterLibrary — Roblox Code Recognition Loop
**File:** `popsim-contract/src/domains/roblox/luau-shatter-library.ts`
**Script:** `npm run test:recognition`

The HAL dark node pattern applied to Luau code repair.

**`CodeShatterCertificate`:**
```typescript
{
  id,              // sha256(fractureHash + timestamp)[:16]
  fractureHash,    // sha256 of broken Luau code
  fingerprint1024, // 1024-D embedding (mxbai-embed-large, single state)
  verifiedFix,     // patch that achieved Diamond-Stable
  moduleName,      // e.g. "CharacterController"
  errorSignature,  // e.g. "attempt to index nil with 'Humanoid'"
  successCount,    // LLM bypass count
  createdAt,
  lastUsedAt
}
```

**API:**
- `logRepair(brokenCode, fix, moduleName, errorSig)` — embed + store cert after successful LLM repair
- `recognize(brokenCode)` — cosine similarity scan. ≥0.98 → instant fix, no LLM
- `preFilterBug(brokenCode)` — convenience wrapper for RepairShop integration
- `stats()` — bypass count, top recognized fractures

**Wired into RepairShopService:**
- `generatePatch()` calls `preFilterBug()` FIRST — if hit, returns instantly (no OpenAI call)
- After successful LLM patch, calls `logRepair()` — issues cert for future recognition
- Both calls are non-fatal (Ollama unavailable → falls through to LLM gracefully)

**Test suite — DIAMOND-STABLE, 23/23 assertions:**
- Pass 1: First repair → cert issued, 1024-D fingerprint stored
- Pass 2: Same bug → recognition hit (similarity=1.0000), LLM bypassed
- Pass 3: Different bug → miss (similarity=0.0000 < 0.98), new cert stored
- Pass 4: Dedup — same fractureHash updates cert, no duplicate created

**Persistence:** `lab/spectral-maps/luau-shatter-library.json`
