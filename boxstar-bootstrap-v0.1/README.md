# 🚀 BoxStar Bootstrap v0.1
**Active Agent Initialization Bundle**

BoxStar Bootstrap is the full-fidelity "Active Tier" of the BoxStar ecosystem. While the Scaffolds provide the "Laws," the Bootstrap provides the **Engine**. 

This bundle initializes your AI agent into a production-verified state, giving it the exact skills, refactoring SOPs, and governance protocols needed to build and manifest game logic autonomously.

## 🎁 What's Inside
*   **The Engine**: `ag-skills.cjs` — The CLI tool for managing agent intelligence.
*   **The Vault**: Full access to the `/skills` library:
    *   **BoxStar Architect**: High-level governance and AST-integrity.
    *   **Sovereign Janitor**: Automated optimization and project hygiene.
    *   **PRD Specialist**: Strategic product and technical requirement documentation.
*   **The Ritual**: `bootstrap-init.sh` — The one-shot installer.

## 🛠️ Installation (The One-Shot)
1. **Drop this folder** into your root repository directory.
2. **Run the Initialization**:
   ```bash
   bash bootstrap-init.sh
   ```
3. **Activate**: Tell your agent:
   > **"Ready to build a game."**

## 📊 Why Bootstrap?
The Bootstrap is a **portable moat**. As we learn from the developer cohort, we update the skills in the Vault. As a subscriber, you receive the latest intelligence "pulses" monthly, ensuring your agent is always running the latest industrial standards.
