# 🕋 BLOXBOX SCAFFOLDS (V0.1) - MANIFEST
## Passive Governance for Agentic Simulations

The BoxStar Scaffolds SKU provides the foundational "Law" for your repository. It is a passive governance layer designed to prevent agent drift and ensure deterministic outcomes without requiring an active runtime engine.

### 📦 WHAT'S IN THE BOX:
- **RLFSP (Root-Level File-Based Security Policy)**: A suite of YAML-based operational policies.
- **The 3-Phase Pipeline (PIPELINE.md)**: The technical blueprint for Ingestion, Validation, and Deployment.
- **Basic Governance Personas**: Markdown-based instructions for standard agent roles.
- **Repository Catalog**: A structural map for standardizing game development repos.

### 🎯 IDEAL FOR:
- Developers who want to "Set and Forget" their repository rules.
- Teams needing a standardized structure for agentic collaboration.
- Static environments where active CLI enforcement is not required.

# 🚀 BLOXBOX BOOTSTRAP (V0.1) - MANIFEST
## Active Orchestration & Sovereign Intelligence

The BoxStar Bootstrap SKU is the premium, active tier of the BoxStar ecosystem. It includes the **Sovereign Bridge** (CLI) and obfuscated high-fidelity agent personas that actively enforce the repository's "Law" in real-time.

### 📦 WHAT'S IN THE BOX:
- **`ag-skills` CLI (The Sovereign Bridge)**: A hardened terminal interface for managing, searching, and installing agentic skills.
- **Obfuscated Skill Vault**: High-fidelity personas (Architect, Janitor, Specialist) protected by the **Sovereign Packer**.
- **Active AAS Enforcement**: Real-time Algorithmic Alignment Scoring via the CLI layer.
- **Automated PDR Generation**: Tools for generating Program Design Reviews directly from the command line.
- **Sovereign Decoder**: Integrated logic that allows your agents to "Read" the hidden laws while keeping the code sterile for the human user.

### 🎯 IDEAL FOR:
- Professional developers building high-stakes autonomous systems.
- Power users who require an active "Mission Control" for their agentic fleet.
- Founders who need to protect their architectural "Secret Sauce" while shipping products.
